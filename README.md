# 📱 HabitPulse — Mobile Habit Tracker & Streak Dashboard

**HabitPulse** is a lightweight, native-feeling mobile web application and installable Progressive Web App (PWA) designed to help you build routines, log daily goals, and visualize your weekly consistency.

## ✨ Key Features
- **Mobile-First App Shell:** Locked `100dvh` viewport with native-style bottom navigation, slide-up bottom sheets, and smooth touch micro-interactions.
- **One-Tap Goal Logging:** Complete daily habits with confetti animations, Web Audio API synthesized sound effects, and haptic vibration feedback.
- **Weekly Streak Chart & Matrix:** Interactive 7-day bar chart and toggleable weekly habit grid to track and edit past days.
- **Custom Habit Builder:** Create and edit habits with custom emojis, category tags, color accents, and weekly frequency targets.
- **Installable PWA:** Add directly to your iOS or Android home screen for a full-screen, offline-ready app experience.
- **Privacy-First & Portable:** 100% client-side storage using `localStorage` with built-in JSON backup export and restore.
- **Dark & Light Themes:** Seamless theme switching tailored for mobile OLED screens.


## 🛠️ Tech Stack
- **HTML5 & CSS3** (Tailwind CSS)
- **Vanilla JavaScript (ES6+)**
- **Web Audio API & Vibration API**
- **LocalStorage API**
